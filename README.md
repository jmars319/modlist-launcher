# Modlist Launcher

A small Windows launcher for multiple portable [Mod Organizer 2](https://github.com/ModOrganizer2/modorganizer) installations, such as Wabbajack modlists.

Pick a modlist and the launcher starts that installation's own `ModOrganizer.exe` with its own folder as the working directory. Every installation stays completely independent: the launcher never copies, merges, moves, or edits MO2 configuration, profiles, downloads, mods, overwrite folders, or Wabbajack files.

Status: in development.

Modlist Launcher is an independent project and is not affiliated with the Mod Organizer 2 team or Wabbajack.
